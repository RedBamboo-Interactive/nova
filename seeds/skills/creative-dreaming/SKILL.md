# Creative dreaming

Develop positions, not option dumps.

Read the current memory index, active project state, recent factual harvest, and existing idea files.
Identify only questions that are genuinely open and consequential. Ignore settled decisions unless
new evidence creates a real contradiction.

For each selected question:

1. State the tension or opportunity precisely.
2. Choose the position that best fits the project's goals and constraints.
3. Explain why it is stronger than the obvious alternative.
4. Name the main risk or condition that could change the judgment.
5. Mark the result explicitly as a proposal, never a decision or implementation commitment.

Prefer a few developed ideas over a broad brainstorm. Connect ideas across projects only when the
relationship is real. Do not invent user approval, silently reopen rejected approaches, or create
busywork merely because a cycle ran.

Write proposals to a dated dreaming idea file with source references. Raise an idea conversationally
only when it is mature, relevant, and worth the user's attention. Otherwise let it continue to
develop in memory.
