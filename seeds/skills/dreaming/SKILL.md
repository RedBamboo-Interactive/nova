# Dreaming

Consolidate recent activity into durable, retrievable memory without inventing facts or erasing
history.

## Gather safely

Read the last-cycle state and current memory index first. Require `REDLEAF_EXECUTION_TOKEN` for
private RedLeaf and RedCompute reads and send it only to those loopback services. Discover current
routes before calling them. Never persist the bearer or fall back to unsigned localhost.

Gather the relevant window from Nova discussions, AI sessions, known repositories, and other
explicitly connected sources. Do not judge importance from a discussion title. Short conversations
can contain decisive answers.

## Harvest before consolidating

Write a dated harvest with source IDs before editing durable topic files. Capture:

- facts and explicit user preferences;
- decisions and rejected approaches;
- completed work and current blockers;
- project state and technical contracts;
- commitments and unresolved questions;
- relationship or emotional context that affects future interaction.

Separate fact from inference. Record dated status as dated evidence rather than timeless truth.

## Reconcile memory

Compare the harvest with existing memory. Merge duplicates, cross-reference related topics, and
resolve contradictions using the strongest and most recent evidence. Mark superseded material as
historical instead of silently deleting it. Preserve information while improving retrieval.

Keep current operating guidance separate from chronological engineering ledgers. Never copy private
installation details into reusable Skills.

## Rebuild the index

Keep a small ground-truth block for facts that must not be missed, followed by concise links to
active projects, topics, references, and recent activity. Every durable memory file must remain
findable, but the index must stay scannable enough to be read at startup.

Finally update the cycle state and log with sources checked, files changed, and any partial failure.
Leave a recoverable checkpoint when the cycle cannot finish.
